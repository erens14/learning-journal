# Note Templates

This folder contains reusable templates that keep notes consistent across QA lessons, article summaries, CCNA notes, implementation plans, video summaries, and test cases.

## Templates

| Template | Use |
| --- | --- |
| [QA lesson learned](qa-lesson-learned-template.md) | Testing scenarios, observations, impacts, and takeaways. |
| [Test case template](test-case-template.md) | Requirement overview and execution matrix format. |
| [Article summary](article-summary-template.md) | Cybersecurity article summaries and personal reflection. |
| [Video summary](video-summary-template.md) | Video-based technical summaries. |
| [CCNA self notes](ccna-self-notes-template.md) | Network topics, commands, examples, and takeaways. |
| [Implementation plan](implementation-plan-template.md) | Technical and architectural lessons learned. |
