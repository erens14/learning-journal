# Note Templates

This folder contains reusable templates for consistent, readable learning and portfolio documentation.

## Templates

| Template | Use |
| --- | --- |
| [QA lesson learned](qa-lesson-learned-template.md) | Concise finding, evidence, impact, outcome, and reusable QA lesson. |
| [Test case template](test-case-template.md) | Preconditions, requirements, and an execution matrix with evidence tracking. |
| [Article summary](article-summary-template.md) | Cybersecurity article summaries and personal reflection. |
| [Video summary](video-summary-template.md) | Video-based technical summaries. |
| [CCNA self notes](ccna-self-notes-template.md) | Network topics, commands, examples, and takeaways. |
| [Implementation plan](implementation-plan-template.md) | Technical and architectural lessons learned. |
